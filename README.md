# ramyaDhanush.github.io

Personal site for Ramya Dhanushkodi: https://ramyadhanush.github.io/

A single static page (`index.html` and `style.css`) with no build step and no dependencies. It follows the light or dark setting of the visitor's device.

To preview locally:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
# open http://127.0.0.1:8000
```
